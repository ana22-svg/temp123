# Loan Risk Prediction System — Complete Implementation Guide

## Project Structure

```
loan-risk-project/
│
├── data/
│   ├── data.csv              ← original dataset (30,000 rows × 4 cols)
│   └── data.json             ← auto-generated by ETL pipeline
│
├── model/
│   ├── regressor.pkl         ← best regression model
│   ├── classifier.pkl        ← best classification model (tuned)
│   ├── scaler.pkl            ← MinMaxScaler
│   ├── le_grade.pkl          ← LabelEncoder for grade column
│   ├── le_target.pkl         ← LabelEncoder for risk_category
│   ├── grid_search.pkl       ← full GridSearchCV object
│   └── training_stats.json   ← loan_amnt mean, installment median, dti threshold
│
├── plots/                    ← all 10 generated visualizations
│
├── preprocess.py             ← shared preprocessing functions
├── train_model.py            ← run ONCE to train + save models
├── app.py                    ← Flask REST API
├── requirements.txt
└── README.md
```

---

## Step-by-Step Procedure

### Step 0 — Setup

```bash
# Create project folder
mkdir loan-risk-project
cd loan-risk-project
mkdir data model plots

# Place data.csv inside data/
# Then install dependencies
pip install -r requirements.txt
```

---

### Step 1 — Run Training (ONE TIME ONLY)

```bash
python train_model.py
```

This executes all 14 phases in sequence:

| Phase | What Happens |
|-------|-------------|
| 1 | CSV → JSON → DataFrame (ETL pipeline) |
| 2 | Missing values filled (mean/median/mode) |
| 3 | Statistical analysis printed (describe, corr, etc.) |
| 4 | Grade encoded via map() AND LabelEncoder |
| 5 | Risk score formula applied + normalized to 0–100 |
| 6 | Feature engineering (is_high_loan, loan_burden, etc.) |
| 7 | Target encoded: risk_category → risk_label (0/1/2) |
| 8 | Stratified 80/20 train/test split |
| 9 | MinMaxScaler fitted on training data |
| 10 | 3 Regression models trained + 5-Fold CV |
| 11 | 3 Classification models trained + Stratified 5-Fold CV |
| 12 | GridSearchCV hyperparameter tuning on Random Forest |
| 13 | All 10 plots saved to plots/ |
| 14 | All models + artifacts saved to model/ |

---

### Step 2 — Start API

```bash
python app.py
```

Server starts at: `http://127.0.0.1:5000`

### Step 3 — Test with Postman

**POST** `http://127.0.0.1:5000/predict`

Body (JSON):
```json
{
    "loan_amnt":   15000,
    "installment": 450.5,
    "dti":         18.5,
    "grade":       "C"
}
```

Response:
```json
{

    "risk_category_clf":   "Medium",
    "class_probabilities": {
```

**POST** `http://127.0.0.1:5000/predict/batch`

## What Each File Does

### preprocess.py
Shared module used by both train_model.py and app.py.
Contains: load_data, handle_missing, print_statistics, encode_grade,
          compute_risk_score, categorize_risk, engineer_features,
          encode_target, scale_features

### train_model.py
Run once. Does everything from data loading to saving .pkl files.
NEVER put training code inside app.py.

### app.py
Only loads pre-trained .pkl files.
Never trains. Never fits a scaler or encoder.
Applies the same preprocessing logic to live inputs.

## Common Issues

| Problem | Fix |
|---------|-----|
| `ModuleNotFoundError: flask` | `pip install flask` |
| `FileNotFoundError: model/classifier.pkl` | Run `python train_model.py` first |
| `Unknown grade 'X'` | Use only A–G for grade field |
| Plots not generating | Check `plots/` folder exists |
